衣见如故 · 面试穿搭私人数字导购

基于具身数字人的面试穿搭「陪伴式决策」原型 · 第四届开放原子大赛参赛作品
参赛赛道：开源基础软件与解决方案（赛道一） 作者：陈倡名 单位：电子科技大学成都学院 开源协议：MIT 仓库：github.com/Nerdlet369/yijian-rugu

一、项目简介

「衣见如故」面向独自逛商场、希望获得可信审美意见的求职者，用一位体贴、坦诚的具身数字人“小衣”，把模糊的“想穿得专业一点”转化为可执行的筛选条件，并在用户犹豫时提供情绪支持、在试穿后给出有边界的穿搭评价，最终落地为带货架位置的购买清单。项目不是给商品目录加一个数字人，而是让数字人承担“需要交流、解释、鼓励和把握分寸”的那段决策过程。

技术形态：移动 Web 前端 + 视觉分析服务 + 本地兜底导购引擎。数字人形象与语音由魔珐星云 SDK 提供；本项目自研重点是导购决策、评价边界控制，以及「无云端也能复现主流程」的本地引擎，而非重建数字人。

二、评审维度说明（按官方权重组织）

30%技术创新评审权重 30%

  • 有边界的视觉评价体系（自研）：服务端调用视觉模型后，系统化约束输出——不评价身材/年龄/健康，不编造摘要未提及的五官、品牌、价格；用 delighted/thoughtful 反应枚举避免无意义惊叹；显式提示照片光线、角度的局限。这是负责任 AI 的具体落地。
  • 鲁棒的视觉分析管线（自研）：手写平衡括号 JSON 解析器防中转截断；当 endpoint 不支持 JSON mode 时自动降级到 prompt-only；处理拒答与“输出不完整”结果；对输入体积、文本长度、请求超时做边界限制。
  • 本地兜底导购引擎（自研，零依赖）：推荐 / 库存 / 清单算法与 DOM 解耦，依据预算、风格、排除色、尺码自动筛选 2-3 套搭配，缺货时自动替换为同风格有货款，并生成带货架位置的购买清单。无需任何外部密钥即可运行，破解“必须云端才能演示”的落地短板。
  • 朋友式交互原则的可执行化（自研）：把“先理解再建议、说明依据、允许犹豫、给替代方案、不为了成交而无条件夸赞”落成系统提示词与前端状态机。
  • 零第三方运行依赖：视觉服务仅用 Node 内置模块，前端为原生 JS 无框架，降低供应链与合规风险。

说明：数字人形象与语音依赖魔珐星云 SDK；本项目刻意不重建数字人，而是聚焦其上层的导购智能与边界控制，避免“简单拼接现成工具”的减分项。

30%场景落地评审权重 30%

  • 真实痛点：应届生/初入职场者独自选购面试装，缺乏可信审美意见与决策陪伴。
  • 可部署、可运行、可测试：提供 docker compose 与 node server.js 两种启动方式；README 给出从克隆到复现主流程的完整步骤；并附 node --test 单测（视觉解析 + 推荐引擎）。
  • 真实能力而非伪造：试穿分析走真实视觉模型（非固定播放）；商品目录为结构化模拟数据（25 件商品 / 8 套搭配 / 价格 / 尺码库存 / 货架位置 / 风格标签），规模达到 MVP 规范。
  • 隐私优先：照片仅用于本次会话、默认不长期保存；自由浏览模式不强制采集任何个人信息；明确标注模拟数据，不把演示库存描述为真实门店。

20%开源治理评审权重 20%

  • 协议合规：采用 MIT 协议（OSI 兼容）。
  • 依赖合规：服务端零第三方包、前端无框架，依赖风险极低。
  • 安全：视觉 API Key 仅存于服务端环境变量 / 项目根 .env，绝不进入前端；.env.example 防误提交。
  • 文档规范：PROJECT_BRIEF（产品定位与边界）、MVP_SPEC（页面/状态机/工具接口/必测交互）、DEMO_SCRIPT（可运行流程与「不能现场宣称的功能」）三件套齐全。
  • 测试：server.test.js 与 recommendation.test.js 覆盖解析、校验与推荐逻辑。
  • 待完善：社区 Issue/PR 响应机制尚处起步阶段，已规划开源协作流程。

20%长期发展评审权重 20%

  • 架构可演进：推荐/库存/清单引擎与渲染层解耦，便于单测与复用；前端已预留魔珐云端与本地双后端切换。
  • 场景扩展：计划接入真实门店商品/库存/室内导航；扩展更多面试风格与身材友好推荐；把本地引擎升级为可插拔 Agent。
  • 组织支撑：依托学校开放原子开源社团（项目部），规划开源协作与贡献机制。
  • 参赛目标：以本原型验证“陪伴式决策”的产品价值，争取产业对接与持续打磨。

四、如何复现

1) 克隆仓库；2)（可选）复制 .env.example 为 .env 并填视觉模型 Key；3) 根目录 node server.js；4) 浏览器打开 http://localhost:8081/。即使不填任何密钥，也能直接进入本地兜底导购，跑通推荐→库存→清单闭环。若要真实数字人，点击“连接数字人”填魔珐 App ID/Secret。
