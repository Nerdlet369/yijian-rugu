# 衣见如故：对话优先原型

这是一个纯前端静态演示页面，展示用户在商场通过手机与数字人“小衣”交流的主流程。当前数字人形象是网页绘制的示意形象，商品、推荐、库存、路线和回复均为模拟数据。

`catalog.json` 收录了用户提供的 6 张服装参考图，图片位于 `assets/products/`。这些图片只作穿搭讨论和界面展示，不代表真实 SKU；价格、尺码、库存、品牌和门店位置都没有接入，页面会明确标为待补充。面试推荐区只挑选藏青外套和酒红针织两张参考图，其他图片保留作浏览/后续讨论素材，不会被一概推荐为面试穿搭。

## 真实照片视觉分析服务

照片分析由项目根目录的 `server.js` 提供。服务器将图片发给 OpenAI Responses API 的图像输入能力；API Key 只从服务器环境变量或项目根目录 `.env` 读取，不会进入浏览器代码。

首次配置：复制项目根目录 `.env.example` 为 `.env`，在 `OPENAI_API_KEY=` 后填入自己的 API Key。当前示例默认测试 `gpt-6.1-sol`，并使用 `https://code1.newcli.com`；如果使用官方接口，将 `OPENAI_BASE_URL` 改为 `https://api.openai.com`。然后在项目根目录运行：

```powershell
node server.js
```

也可以使用 Docker Compose 启动：

```powershell
docker compose up --build
```

浏览器访问 `http://localhost:8081/`。Docker 方式需要先在项目根目录准备 `.env`；不要把 `.env` 提交到代码仓库。

浏览器打开 `http://localhost:8081/`。不要再用 `python -m http.server` 作为真实识图页面的服务，因为它不能处理 `/api/analyze-photo` 接口。没有配置有效 API Key、网络不可用或模型请求失败时，网页会显示错误，不会伪造识图结果。

默认只监听本机 `127.0.0.1`。不要把带有个人 API Key 的分析服务暴露到公共网络；如确需手机局域网测试，只在可信私人网络临时配置 `HOST=0.0.0.0`，完成后改回本机监听。

## 在电脑上查看

直接用 Chrome 或 Edge 打开 `index.html`。把浏览器窗口缩窄，可以查看手机布局。

## 在手机上查看

手机不能直接访问电脑上的 `D:` 文件路径。让电脑启动静态服务器，然后手机和电脑连接同一个 Wi-Fi：

```powershell
cd D:\魔钥科技赛题\prototype
python -m http.server 8080 --bind 0.0.0.0
```

查看电脑局域网 IP：

```powershell
ipconfig
```

在手机浏览器访问 `http://电脑局域网IP:8080/`，例如 `http://192.168.1.23:8080/`。如果 Windows 防火墙提示，允许 Python 在专用网络通信。手机和电脑必须连接同一个 Wi-Fi；手机上不要使用 `localhost` 或 `127.0.0.1`，那会指向手机自身。

说明：这个局域网 HTTP 地址适合查看主界面和测试拍照/相册。真实魔珐 SDK 的麦克风、WebSocket 和部分浏览器能力通常要求 `localhost` 或 HTTPS；要在手机上测试真实数字人，应把页面部署到 HTTPS，或使用带 HTTPS 的临时隧道/测试域名。

## 第一步：验证真实魔珐 SDK

1. 登录魔珐星云，在应用中心创建“驱动应用”，设置虚拟人角色、音色和表演风格，复制 `App ID` 与 `App Secret`。
2. 启动本地服务器后打开 `http://localhost:8080/sdk-smoke-test.html`。不要双击 HTML 文件，SDK 的麦克风和 WebSocket 链路需要 `localhost` 或 HTTPS。
3. 在页面右侧临时填写 App ID 和 App Secret，点击“初始化数字人”。凭证只保存在当前页面内存中，不会写入项目。
4. 初始化成功后先点“发文本”验证播报。测试语音时点“开始识别”，说完整句子，再点“停止识别”；查看“识别文本”框，手动修改或补全后点“发送给数字人”。现在识别结果不会自动触发回答，事件日志会记录 Agent 状态、ASR 结果、对话状态和错误。
5. 四项都通过后，打开主界面 `http://localhost:8081/`，点击右上角“连接数字人”，临时填写同一组 App ID/App Secret。初始化完成后，左侧 CSS 示意形象会替换成真实数字人；文字模式会调用 `agent.ask()`，语音模式会调用 `agent.startASR()`，打断按钮会调用 `agent.interrupt('speak')`。拍照和相册仍由主界面的图片输入处理。

当前代码实际使用的 SDK 链路是 `XingyunAvatarAgent`、`init()`、`ask()`、`startASR()`、`stopASR()`、`interrupt('speak')` 和 `destroy()`。不要把未在目标版本中验证过的 `speak()`、SSML、独立表情或动作控制当作必备能力；旧版 SDK 可能只支持让 Agent 播报文本。视觉模型只把照片转换为分析摘要，数字人拿到的是摘要与用户问题，并非直接接收图片像素。验证页已设置 `features.auto_send_asr_to_llm: false`：ASR 只返回识别文本，业务端确认后再执行 `agent.ask(text)`，避免短暂停顿造成多轮自动回答。当前验证页见 [sdk-smoke-test.html](D:/魔钥科技赛题/prototype/sdk-smoke-test.html)。

## 当前可以演示

- 在“语音陪逛 / 文字输入”之间切换；
- 文字模式下可输入文字；支持的浏览器可点麦克风进行语音转文字，识别后需检查并手动发送；
- 语音模式里点“模拟插话”，查看播报停止、用户新话语进入对话并得到回应的界面效果；支持浏览器语音合成时会朗读数字人的回复；
- 在聊天里自然输入需求，或点击开场建议；
- 通过固定的“拍照”入口调用手机相机，或通过“相册”入口选择已有照片；
- 照片会作为聊天消息显示；运行 `node server.js` 并配置视觉模型 API Key 后，由真实视觉模型分析并把分析摘要连同用户问题传给数字人；只发照片不会触发数字人回答，之后再提问时会承接这张照片。真实数字人的具体表情和动作取决于当前 SDK 是否提供并允许调用相应接口，不能仅凭网页端提示保证显式动作；
- 询问推荐后，从 `catalog.json` 读取商品卡片资料；该文件目前明确标注为演示样例，不代表真实商品、价格、库存或位置；
- 继续追问位置、尺码/库存或调整风格，回复会显示在同一条聊天流里。

主界面已经提供真实 SDK 的接入入口；商品推荐读取 `catalog.json`，但当前仍是演示样例。可在每个商品的 `image` 字段填写站内图片路径（例如 `assets/products/item-001.jpg`），再把图片放入相应目录；未配置图片时会显示“图片待补充”。真实库存、门店位置和商品接口/室内导航尚未接入。照片分析需要配置真实视觉模型 API Key 才可运行。`sdk-smoke-test.html` 仍是独立的真实 SDK 验证页。正式部署时不要把 App Secret 或视觉模型 API Key 写进前端代码或公开仓库；用户照片会发送到所配置的视觉模型服务进行分析。
